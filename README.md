# 🚗 Cab Ride Price Prediction

## 📌 Description
This project predicts cab ride prices based on trip features such as distance and passenger count using machine learning techniques. It includes a user-friendly web interface built with Streamlit.

## 🚀 Features
- Data preprocessing and cleaning  
- Machine learning model for price prediction  
- Interactive UI using Streamlit  
- Real-time price estimation  

## 🛠 Technologies Used
- Python  
- Pandas, NumPy  
- Scikit-learn  
- Streamlit
