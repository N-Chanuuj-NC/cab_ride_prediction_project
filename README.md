# 🚗 Cab Ride Price Prediction

## 📌 Description
This project predicts cab ride prices based on trip details such as distance, number of passengers, and other ride-related features using machine learning.

## 🚀 Features
- Data preprocessing and cleaning
- Feature selection and engineering
- Price prediction using regression model
- Interactive web interface using Streamlit

## 🛠 Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit

## 📊 Dataset
The dataset contains ride-related features such as:
- Distance
- Passenger count
- Fare amount

## ▶️ How to Run
1. Clone the repository  
2. Install dependencies:
   pip install -r requirements.txt  
3. Run the application:
   streamlit run src/app.py
