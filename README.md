# Uber Ride Price Prediction 🚗

## 📌 Description
This project predicts Uber ride prices based on trip features such as distance and passenger count using machine learning techniques.

## 🚀 Features
- Data preprocessing and cleaning
- Feature engineering
- Price prediction using regression model
- Interactive web interface (Streamlit)

## 🛠 Technologies
- Python
- Pandas, NumPy
- Scikit-learn
- Streamlit

## ▶️ How to Run
pip install -r requirements.txt  
streamlit run src/app.py
